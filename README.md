# LangChain_SubAgents

## Overview
LangChain_SubAgents is a project designed to facilitate the management and interaction of multiple agents using the LangChain framework. It focuses on simplifying the process of building, deploying, and maintaining sub-agents within the LangChain ecosystem.

## Features
- **Easy Integration**: Seamlessly integrate with existing LangChain workflows.
- **Modular Design**: Built with a modular approach to simplify the management of various agents.
- **Scalability**: Designed to handle multiple agents efficiently.
- **Robust Documentation**: Comprehensive guides and examples for easy onboarding.

## Requirements
- Python 3.7 or higher
- LangChain library
- Additional dependencies are documented in the requirements.txt file.

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/vkeerthi1/LangChain_SubAgents.git
   ```
2. Navigate into the project directory:
   ```bash
   cd LangChain_SubAgents
   ```
3. Install the necessary dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
To run the project, execute the following command:
```bash
python main.py
```

### Configuration
Configuration files are located in the `config/` directory. Modify `config.yaml` to set your parameters accordingly.
